Proyek contoh · Manufaktur & Industri · Digital Engineering

Angka dummy untuk pratinjau.

Tantangan

Penghentian dan output dicatat manual di akhir setiap shift, sehingga masalah terlambat diketahui dan akar penyebabnya sulit dianalisis.

Yang kami kerjakan

  • Survei lokasi dan pemilihan sensor
  • Setup gateway dan konektivitas
  • Dashboard pemantauan dan notifikasi
  • Integrasi dengan catatan pemeliharaan

Solusi

Sensor dan gateway mengumpulkan sinyal mesin, platform IoT menyimpan dan mengolahnya, dan supervisor melihat status lini serta penyebab downtime secara real-time.

  1. Sensor mesin
  2. Edge gateway
  3. IoT platform
  4. Time-series database
  5. Dashboard operasional

Hasil

Supervisor melihat penghentian saat terjadi dan tim pemeliharaan bertindak sebelum kerusakan meluas.
