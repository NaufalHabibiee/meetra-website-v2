The challenge

Ageing on-premise servers run near capacity and the recovery plan has never been tested end to end.

What we did

  • Application portfolio assessment
  • Landing zone and network design
  • Phased migration waves
  • Backup, replication and DR drills

The solution

Applications are grouped into waves, migrated to a secured landing zone and protected by replication to a recovery site that is tested every quarter.

  1. On-premise data center
  2. Secure connectivity
  3. Cloud landing zone
  4. Replication & backup
  5. DR runbooks

The outcome

Capacity limits are removed and recovery is proven with regular drills instead of assumed.
