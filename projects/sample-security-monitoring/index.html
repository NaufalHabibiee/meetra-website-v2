The challenge

Critical systems produce security logs, but there is no central monitoring and no agreed procedure for handling incidents.

What we did

  • Vulnerability assessment and penetration test
  • Log source onboarding
  • Detection use cases
  • Incident response playbooks

The solution

Findings from the assessment are prioritized and remediated, while a monitoring platform collects and correlates logs and alerts the response team according to playbooks.

  1. Log collectors
  2. SIEM platform
  3. Detection rules
  4. Ticketing integration
  5. Reporting dashboard

The outcome

Security events from critical systems are monitored centrally and handled with agreed playbooks.
