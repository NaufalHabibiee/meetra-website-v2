Internal knowledge assistant for policy and procedure documents

Sample project · Banking & Financial Services · AI & Intelligence

60%less time spent searching for policy documents
3×faster answers to staff questions

Dummy figures for the preview.

The challenge

Policies and procedures are spread across shared folders and intranet pages, so staff spend time searching and sometimes rely on outdated versions.

What we did

  • Knowledge source inventory and access rules
  • Document ingestion and indexing pipeline
  • Chat interface with source citations
  • Answer quality evaluation set

The solution

A retrieval-augmented generation (RAG) service indexes approved documents, retrieves relevant passages according to the user’s access rights, and generates answers that cite their sources.

  1. Document connectors
  2. Vector index
  3. Access-aware retrieval API
  4. LLM gateway with guardrails
  5. Web chat client

The outcome

Employees find approved answers with sources in seconds instead of searching shared folders.
